# TTwin harness — Teacher Model and Student Model

These files are **agent law** for the live site (https://khkreddy.github.io/TTwin/). An agent loads them as the harness. They are not a second runtime.

**Read order:** `00_PRECEDENCE.md` → `10_KERNEL.md` → `20_TEACHER_MODEL.md` + `30_STUDENT_MODEL.md` → the rest as needed.

**Running philosophy.** Most work is already ingested. Retrieve, typeset, score, and lookup are deterministic. AI synthesizes only in five legal slots (four teacher, one student). Public UI says **AI**, never a vendor name.

Frozen exam.v1, ISO-GEN L20, live V15, and the public NCERT map sha are not rewritten.
